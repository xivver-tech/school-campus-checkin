# Rowad Nahda Private — Tiznit · Campus Check-In

Base app with **French / Arabic / English** UI.

## Languages
Tap **FR** · **AR** · **EN** in the header (Arabic uses RTL layout).

Default language: **French**.

## Pre-configured
| Setting | Value |
|--------|--------|
| School | Rowad Nahda Private - Tiznit |
| GPS | 29.6974, -9.7316 (Tiznit center) |
| Radius | 200 m |
| Hours | 08:00 – 16:00 |
| Late after | 08:15 |

## Run
```bash
pip install -r requirements.txt
python app.py
```
Phone: `http://YOUR-PC-IP:5050` → Add to Home Screen
